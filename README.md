
  # Premium Personal Portfolio Website

  This is a code bundle for Premium Personal Portfolio Website. The original project is available at https://www.figma.com/design/WpHsfAtqWPe7xgOmlqlmH3/Premium-Personal-Portfolio-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Deploying for free

  This project is ready for free static hosting on Netlify or Vercel.

  ### Netlify

  1. Push this folder to a GitHub repository.
  2. In Netlify, choose **Add new site** then **Import an existing project**.
  3. Use these settings:
     - Build command: `npm run build`
     - Publish directory: `dist`

  ### Vercel

  1. Push this folder to a GitHub repository.
  2. In Vercel, choose **Add New Project** and import the repository.
  3. Vercel will use `vercel.json` to build with `npm run build` and publish `dist`.
