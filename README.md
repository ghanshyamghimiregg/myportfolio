# Ghanshyam Ghimire - Personal Portfolio

Welcome to the repository for my personal portfolio website! This project is a dynamic, interactive web experience built to showcase my work across different fields, including **AI Development**, **Hackathons**, and my journey in **Music**.

🌐 **Website:** [ghanshyamghimire.com.np](https://ghanshyamghimire.com.np)

---

## ✨ Features

- **🎨 Modern UI/UX:** A sleek, dark-mode-first design featuring smooth micro-interactions and scroll animations.
- **🤖 AI & Freelance Showcase:** Highlights of my Artificial Intelligence projects, freelancing experience, and technical skills.
- **🏆 Hackathons Timeline:** A dedicated section celebrating hackathon wins, participation, and projects.
- **🎸 Music Journey:** An interactive gallery and storytelling section dedicated to my musical journey, songs, and background.
- **📱 Fully Responsive:** Carefully crafted layouts that look great on desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

This project was built using modern web technologies:

- **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://motion.dev/) & [Tailwind Animate CSS](https://github.com/jamiebuilds/tailwindcss-animate)
- **UI Components:** [Radix UI](https://www.radix-ui.com/) (Headless, Accessible Components)
- **Carousels:** [Embla Carousel](https://www.embla-carousel.com/)

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/ghanshyamghimiregg/myportfolio.git
cd myportfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```
The site will be available locally at `http://localhost:5173`.

## 📦 Deployment

This project is optimized for deployment on Vercel and Netlify out of the box.

- **Vercel**: Import the repository in Vercel. It will automatically detect the settings from `vercel.json`.
- **Netlify**: Connect your GitHub repo, and it will use the `dist` directory and `npm run build` as configured.
